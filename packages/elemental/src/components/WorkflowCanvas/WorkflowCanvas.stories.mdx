# WorkflowCanvas

A flexible React Flow-based canvas component for building workflow diagrams, process flows, and node-based visualizations with automatic layout, centering, and zoom controls.

## Live Example

<Canvas>
    <WorkflowCanvasExample />
</Canvas>

## Installation

```jsx
import FlowCanvas, { Handle, Position, EdgeLabelRenderer, getBezierPath } from "@birdeye/elemental/core/components/WorkflowCanvas";
import ZoomPopover from "@birdeye/elemental/core/components/WorkflowCanvas/components/ZoomPopover";
import BaseNode from "@birdeye/elemental/core/components/WorkflowCanvas/components/BaseNode";
import BaseEdge from "@birdeye/elemental/core/components/WorkflowCanvas/components/BaseEdge";
```

## Basic Usage

<Source
  code={`import React, { useState, useCallback } from 'react';
import FlowCanvas, { Handle, Position } from 'components/WorkflowCanvas';
import ZoomPopover from 'components/WorkflowCanvas/components/ZoomPopover';

// Define custom node component
const CustomNode = ({ data, selected }) => (

<div style={{
        padding: '16px 24px',
        borderRadius: '8px',
        background: selected ? '#e3f2fd' : '#ffffff',
        border: \`2px solid \${selected ? '#2652ED' : '#e0e0e0'}\`,
    }}>
<Handle type="target" position={Position.Top} />
<div>{data.label}</div>
<Handle type="source" position={Position.Bottom} />
</div>
);

// Define node types
const nodeTypes = { custom: CustomNode };

// Define initial nodes and edges
const initialNodes = [
{ id: 'node-1', type: 'custom', position: { x: 0, y: 0 }, data: { label: 'Start' } },
{ id: 'node-2', type: 'custom', position: { x: 0, y: 150 }, data: { label: 'End' } },
];

const initialEdges = [
{ id: 'edge-1-2', source: 'node-1', target: 'node-2', type: 'smoothstep' },
];

function MyWorkflow() {
const [nodes, setNodes] = useState(initialNodes);
const [isZoomOpen, setIsZoomOpen] = useState(false);

    return (
        <FlowCanvas
            nodes={nodes}
            edges={initialEdges}
            setNodes={setNodes}
            layoutMode="vertical"
            invokeFitView={true}
            reactFlowProps={{ nodeTypes }}
            panels={[{
                position: 'top-right',
                content: (
                    <ZoomPopover
                        isOpen={isZoomOpen}
                        handleZoomPopover={() => setIsZoomOpen(!isZoomOpen)}
                        handleZoomCallback={() => setIsZoomOpen(false)}
                    />
                ),
            }]}
        />
    );

}`}
language="jsx"
/>

## Core Components

### FlowCanvas

The main wrapper component that provides ReactFlowProvider context and handles layout, centering, and node interactions.

**Props:**

| Prop              | Type                         | Default      | Description                              |
| ----------------- | ---------------------------- | ------------ | ---------------------------------------- |
| `nodes`           | `Node[]`                     | required     | Array of nodes to display                |
| `edges`           | `Edge[]`                     | required     | Array of edges connecting nodes          |
| `setNodes`        | `function`                   | required     | Setter function for updating nodes       |
| `layoutMode`      | `'vertical' \| 'horizontal'` | `'vertical'` | Direction of the automatic layout        |
| `selectedNodeId`  | `string`                     | -            | Currently selected node ID               |
| `actionPanel`     | `ReactNode`                  | -            | Panel component to show above the canvas |
| `showActionPanel` | `boolean`                    | `false`      | Whether to show the action panel         |
| `panels`          | `Panel[]`                    | `[]`         | Array of panel configurations            |
| `reactFlowProps`  | `object`                     | `{}`         | Additional props passed to ReactFlow     |
| `nodeClickConfig` | `object`                     | `{}`         | Configuration for node click behavior    |
| `fitViewConfig`   | `object`                     | `{}`         | Configuration for fit view behavior      |
| `className`       | `string`                     | -            | Additional CSS class for the wrapper     |
| `style`           | `object`                     | `{}`         | Additional inline styles                 |

### ZoomPopover

A dropdown popover component providing zoom controls for the canvas.

**Props:**

| Prop                 | Type       | Default  | Description                             |
| -------------------- | ---------- | -------- | --------------------------------------- |
| `isOpen`             | `boolean`  | required | Whether the popover is open             |
| `handleZoomPopover`  | `function` | required | Toggle function for the popover         |
| `handleZoomCallback` | `function` | required | Callback after zoom action              |
| `isVertical`         | `boolean`  | `true`   | Layout orientation for fit view padding |
| `removeFitView`      | `boolean`  | `false`  | Hide the "Zoom to fit" option           |
| `wrapperClass`       | `string`   | -        | Additional CSS class                    |

### BaseNode

A reusable base component for creating custom workflow nodes with configurable handles and states.

**Props:**

| Prop                    | Type       | Default | Description                                |
| ----------------------- | ---------- | ------- | ------------------------------------------ |
| `containerRef`          | `ref`      | -       | React ref for the container element        |
| `containerClassname`    | `string`   | -       | CSS class for the container                |
| `onMouseLeaveContainer` | `function` | -       | Handler for mouse leave event              |
| `isLoading`             | `boolean`  | `false` | Whether to show loading state              |
| `nodeDataConfig`        | `object`   | `{}`    | Configuration for node content (see below) |
| `sourceHandleData`      | `array`    | `[]`    | Array of source handle configurations      |
| `targetHandlePosition`  | `Position` | -       | Position for the target handle             |

**nodeDataConfig structure:**

-   `defaultStateJSX` - JSX to render in default state
-   `loadingStateJSX` - JSX to render in loading state
-   `customJSX` - Additional custom JSX
-   `className` - CSS class for the content wrapper

<Source
    code={`import BaseNode from 'components/WorkflowCanvas/components/BaseNode';
import { Position } from 'components/WorkflowCanvas';

const MyNode = ({ data, selected }) => {
const nodeDataConfig = {
defaultStateJSX: <div>{data.label}</div>,
loadingStateJSX: <div>Loading...</div>,
className: 'my-node-content',
};

    const sourceHandleData = [
        { id: 'source-1', position: Position.Bottom, style: { visibility: 'visible' } }
    ];

    return (
        <BaseNode
            containerClassname="my-node"
            nodeDataConfig={nodeDataConfig}
            sourceHandleData={sourceHandleData}
            targetHandlePosition={Position.Top}
            isLoading={false}
        />
    );

};`}

### BaseEdge

A reusable base component for creating custom workflow edges with drag-drop support and custom labels.

**Props:**

| Prop                      | Type     | Default | Description                               |
| ------------------------- | -------- | ------- | ----------------------------------------- |
| `pathData`                | `string` | -       | SVG path data for the edge                |
| `pathStyle`               | `object` | -       | Style object for the visible path         |
| `invisiblePathDropConfig` | `object` | -       | Configuration for drag-drop functionality |
| `edgeLabelConfig`         | `object` | -       | Configuration for edge labels             |

**invisiblePathDropConfig structure:**

-   `isDraggingNode` - Whether a node is being dragged
-   `strokeWidth` - Width of invisible drag area
-   `handleDragOver`, `handleDragLeave`, `handleDrop` - Drag event handlers

**edgeLabelConfig structure:**

-   `customJSX` - Custom JSX to render as label
-   `isLoading` - Hide default add button when true
-   `addButtonStyle` - Style for the add button

<Source
    code={`import BaseEdge from 'components/WorkflowCanvas/components/BaseEdge';
import { getBezierPath } from 'components/WorkflowCanvas';

const MyEdge = ({ sourceX, sourceY, targetX, targetY, sourcePosition, targetPosition }) => {
const [edgePath, labelX, labelY] = getBezierPath({
sourceX, sourceY, sourcePosition,
targetX, targetY, targetPosition,
});

    return (
        <BaseEdge
            pathData={edgePath}
            pathStyle={{ stroke: '#2652ED', strokeWidth: 2, fill: 'none' }}
            invisiblePathDropConfig={{ isDraggingNode: false, strokeWidth: 20 }}
            edgeLabelConfig={{
                customJSX: (
                    <div style={{
                        position: 'absolute',
                        transform: \`translate(-50%, -50%) translate(\${labelX}px,\${labelY}px)\`,
                    }}>
                        <span>Label</span>
                    </div>
                ),
                isLoading: false,
            }}
        />
    );

};`}

## Best Practices

1. **Always provide `setNodes`** - Required for automatic layout to work
2. **Use unique node IDs** - Essential for proper edge connections
3. **Define node types** - Pass custom node components via `reactFlowProps.nodeTypes`
4. **Control zoom state externally** - Manage ZoomPopover open state in parent component
5. **Use `layoutMode` for direction** - Let the component handle positioning automatically
