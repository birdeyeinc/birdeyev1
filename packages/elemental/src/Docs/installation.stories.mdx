# Prerequisites

<br />

### Peer Dependencies
You need to install below npm packages in your project before using `@birdeye/elemental` library
```bash
npm install react react-dom react-onclickoutside
```
```bash
yarn add react react-dom react-onclickoutside
```

### Icon
If you are using component which have icons then you need to import `icomoon` library in your project 
```
@import url("https://cdn.icomoon.io/101518/phoenix/style.css?hlhu9z");
```

# Installation
<br />

### Set Repository
`@birdeye/elemental` is a private package so we need to set birdeye repository to install the package.
```bash
npm config set @birdeye:registry http://npm-repo.birdeye.internal:4873
```

### Download package
To download the package developer should connected to the birdeye VPN.
```bash
npm install @birdeye/elemental
```

```bash
yarn add @birdeye/elemental
```
